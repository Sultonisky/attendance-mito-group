# Security Policy

## Scope

This repository is intended for internal use by Attendance MITO Group only.
It is not an open-source project and is not intended for public disclosure,
third-party contribution, or external distribution.

## Reporting a security issue

If you identify a security vulnerability or sensitive issue in this project,
please report it privately and responsibly.

Send the report to the internal security contact or designated project maintainer
for Attendance MITO Group.

Please include:
- a description of the issue
- affected component or file
- reproduction steps if applicable
- potential impact
- suggested remediation if available

Do not disclose the issue publicly until an internal review and remediation plan
has been completed.

## Handling expectations

- Reports will be reviewed internally by the project maintainers.
- We will assess severity and impact in the context of internal business use.
- We may request additional details before remediation.
- We will coordinate fixes and validation within the internal team.

## Responsible disclosure

We ask that security researchers and internal contributors follow responsible
responsible disclosure practices and avoid public publication of vulnerabilities
before they are addressed.

## Important notice

This repository is not a public security advisory program and does not accept
anonymous public submissions through public issue trackers or public pull
requests for security-sensitive matters.
